# Projet 2 — Landing page produit (No-Code)
---

## 📋 Marche à suivre

### Étape 1 — Choisir l'outil No-Code

-  Comparer rapidement : **Carrd** (simple), **Wix** (facile), **Webflow** (plus complet)
-  Créer un compte gratuit

> 💡 Pour un débutant, Carrd est le plus rapide pour une page unique.

### Étape 2 — Définir le message clé

-  Choisir un produit (réel ou fictif)
-  Écrire l'**accroche** : une phrase courte qui donne envie
-  Lister 3 **bénéfices** (ce que le produit apporte au client)
-  Choisir l'**appel à l'action** (ex. : « S'inscrire », « Être prévenu du lancement »)

### Étape 3 — Construire la page

Structure conseillée, de haut en bas :

1. **Titre + accroche** (+ bouton d'action)
2. **Image ou visuel** du produit
3. **Bénéfices** (3 blocs)
4. **Appel à l'action** (formulaire email ou bouton)
5. **Pied de page** (contact)

-  Choisir 2 couleurs et 1 police maximum
-  Vérifier l'affichage sur **mobile**

### Étape 4 — Publier la page

-  Cliquer sur **Publish / Publier**
-  Tester le lien dans un navigateur
-  Copier le lien (ou exporter le HTML si l'outil le permet)
